# Archived Generation Schemes (退避された旧生成方式)

## 概要
本ディレクトリは、VTA分析の抽出方式が「粒度反復方式（`refined-chain`）」に一本化されたことに伴い、退避・保管された旧抽出方式（`event-chain`、`fulltext-ledger`）の実装を安全に保存するためのアーカイブ領域です。

- **`refined-chain`（粒度反復方式）への一本化理由**:
  - `refined-chain` は、変動要因から帰結への到達性（C1/C3）および人間の認知負荷（C5: レーン数・カード数・交差数）を多目的評価関数によって反復評価し、最もバランスの取れたツリー（best-so-far）を探索するため、他の単発抽出方式と比較して実用上圧倒的に優れた品質が得られるため。
  - ユーザーが毎回生成方式を選択する認知的負担を解消するため。

## 退避ファイル一覧
1. **`eventChainScheme.ts`**: 旧「事象連鎖方式（`event-chain`）」。全文連鎖構成指示を正規化プロンプトに動的付加し、主体ランキングで集約して射影する方式。
2. **`fulltextLedgerScheme.ts`**: 旧「全文正規化・TSV台帳方式（`fulltext-ledger`）」。基本プロンプトで正規化し、主体ランキングで集約して射影する方式。

## 復元方法（将来再統合が必要になった場合）
1. `registry.ts` または `client.ts` で本アーカイブ内の各方式オブジェクトをインポートします。
2. `generationRegistry` の初期化配列に、復元したい方式オブジェクトを追加します。
3. `ScenarioInputSection.tsx` の UI に選択用プルダウンを再配置し、選択された `schemeId` を渡すようにします。
