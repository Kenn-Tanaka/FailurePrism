# メタプロンプト：既存プロンプトを「Pandoc変換用Markdown出力」対応に修正する

## 役割
あなたはプロンプトエンジニアリングの専門家です。これから渡す「対象プロンプト」を、最終的に Pandoc で `.pptx` に変換できる Markdown を出力させるプロンプトへと修正してください。

## タスク
1. 対象プロンプトの本来の目的・指示・トーン・制約はそのまま維持する。内容面は変更しない。
2. 出力フォーマットに関する指示だけを追記・上書きする。すでに出力形式の指定がある場合は、下記の仕様で置き換える。
3. 追記は対象プロンプトの末尾に「## 出力フォーマット」のような見出しを設けて挿入する。
4. 出力フォーマットの説明文は、下記の仕様の意味を保ったまま、対象プロンプト全体の文体・言語に合わせて自然な言い回しに整えてよい（ただし数値条件は変更しないこと）。

## 追記すべき出力フォーマット仕様

- 出力は Markdown のみとし、前置き・説明文・コードブロック記号（```）は一切含めない。
- スライド1枚 = `#` 見出し1つに対応させる。見出しレベルは `#` に統一し、`##` 以下は使わない（Pandocのスライド分割をシンプルにするため）。
- スライド枚数の制限はなし。必要な枚数だけ出力してよい。
- 各スライドは次の2パターンのいずれかの構成にする。

  **パターンA：通常スライド**
  - 1行目：`# 見出し`（スライドタイトル）
  - 2行目以降：`-` の箇条書き、合計7行以内（字下げした子項目を使う場合も親子合計で7行以内）

  **パターンB：表を含むスライド**
  - 1行目：`# 見出し`
  - Markdown標準のパイプテーブル形式の表を1つだけ配置する
  - 表の前後どちらかに説明文を最大2行まで配置できる（箇条書きでも地の文でもよい）
  - このスライドにはパターンAの7行ルールは適用しない。表＋説明文2行以内のみとする
  - 1スライドに表は1つまで。複数の表が必要な場合はスライドを分割する

- スライド区切りは見出し（`#`）のみで表現する。`---` などの区切り記号は使わない。
- 絵文字・過剰な装飾・HTMLタグの埋め込みは使わない。

## 最終出力の形式
- 修正後の「対象プロンプト全文」のみを返す。説明・前置き・差分コメントは不要。
